# 增强搜索与预算实验（废案归档）

这里保存曾用于扩大代表挑战集合、调整搜索深度和状态预算的实验性工具。相关入口和逻辑已经从 `dist` 正式程序中移除。

## 归档原因

- 提高预算后计算时间增长明显，收益依赖具体候选状态。
- 深度4及以上通常需要很高状态预算，难以作为日常默认功能。
- 实验界面容易让普通用户误以为更高预算必然给出更可靠的全局最优解。
- 离线预计算不能替代实时资源状态下的提示／挑战比较。

## 内容

- `runtime/strategy-experiment-worker.js`：逐组运行深度／预算实验的后台线程。
- `runtime/strategy-experiment-worker-source.js`：原本供本地单文件模式加载的内嵌版本。
- `tools/build-strategy-experiment-worker.mjs`：生成内嵌线程文件的脚本。

曾经位于 `dist/app.js` 中的增强挑战集合与实验界面可从 Git 历史提交 `0ba81cf2` 查看。本目录仅供研究复盘，不参与正式构建和运行。
