# 第一猜参考库（废案归档）

这里保存曾用于预计算全部初始揭示状态首步的离线参考库。相关数据、生成脚本、界面开关及规模测试接入均已从正式程序中移除。

## 归档原因

- 修正数值字段索引和跨题使用逻辑后，约 250 轮规模测试的九题全通率约为 97%–98%，未显示出相对稳定实时求解器的可靠提升。
- 固定规范资源下计算的首步难以代表后续题不同提示／挑战库存的真实价值。
- 大候选状态仍依赖有限挑战覆盖集合、深度 3 搜索和资源续值近似；提高状态预算只能更精确地求解这一近似模型。
- 正式功能应保持单一且可验证，避免无实证收益的离线优先项干扰实时策略。

## 内容

- `runtime/first-action-reference.js`：修正数值字段后生成的 218 个参考状态。
- `tools/build-first-action-reference.mjs`：可恢复计算的参考库生成脚本。

该目录仅供实验复盘，不会被 `dist/index.html` 加载，也不参与手动求解或规模测试。
