# 资源路线规划（废案归档）

本目录保存曾用于比较提示与挑战的“资源路线规划”实验。它已经从 `dist` 正式程序中移除，不会被本地版加载，也不参与手动推荐或规模测试。

## 结论

方案以整题资源路线样本和滚动抽样比较“先提示”与“先挑战”。小规模开发验证一度显示接近稳定方案，但扩大到 200 个完整活动、9 题／11 提示／36 挑战、8 组抽样后，结果为：

- 平均解题数：8.95 / 9
- 全题完成率：95.0%（190 次 9 题、9 次 8 题、1 次 7 题）
- 平均首次相符项：53.87
- 平均消耗：34.28 次挑战、5.83 次提示
- 运行时间：249.2 秒
- 计算规模：8022 次决策、123592 条行动样本

结合多次实操，方案在效果、稳定性和计算成本上均未优于现有稳定搜索，因此不再继续优化或实装。该结论也说明先前 100 轮测试不足以支持正式替换。

## 目录

- `runtime/`：曾在浏览器中运行的数据与工作线程。
- `tools/`：路线生成、抽样、规模测试和独立验证脚本。
- `tests/`：浏览器工作线程测试。
- `模型与资源路线审计计划.md`：设计过程、边界及被否决方案记录。

这些文件只用于历史复盘，移动后未保证命令行相对路径仍可直接运行。若未来重新研究，应建立新的实验分支并重新验证，而不是直接恢复到正式程序。
