# 卡片解码者

基于《游戏王 MASTER DUEL》怪兽卡判定字段的本地猜谜求解器。

## 使用

直接打开 `dist/index.html`。程序完全在本地浏览器运行，不上传活动进度。

严格模式用贝叶斯候选后验和自适应策略树统一比较提示与挑战；小状态使用完整 Bellman 穷举，大状态明确标记为受限深度可行策略。规模测试在后台线程中执行与实操相同的推荐逻辑。

详细规则、模型边界和实验结果见：

- `使用说明.txt`
- `模型复审与实现规格.md`
- `资源价值实验报告.md`

## 可选卡图

仓库不包含卡图、壁纸和下载日志。可运行 `tools/download-card-images.mjs` 下载所需卡图资源。

## 数据说明

`dist/cards-data.js` 包含求解所需的怪兽判定组数据。活动实际卡池可能与公开数据存在少量差异。
