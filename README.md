# 卡片解码者

《游戏王 MASTER DUEL》“卡片解码者”活动的本地辅助求解器。输入已揭示的线索和每次挑战结果，程序会持续缩小候选卡池，并推荐下一步使用提示还是挑战哪张卡。

> 本项目是非官方研究与辅助工具，不能消除目标卡和提示字段带来的随机性。

## 主要功能

- 完整卡片数据库支持卡名搜索、多条件筛选、排序以及列表／卡图视图；同一字段可取多个值的并集
- 可切换“仅显示符合当前已知信息”，根据边框、属性、种族、等级／阶级／连接、攻击力和守备力筛选候选卡
- 区分挑战反馈的“字段点亮”和“严格相符”：复合灵摆边框部分重叠可揭示边框，但不会误计奖励或全中
- 在同一套策略模型中比较“使用提示”与“进行挑战”
- 显示推荐行动、完全猜中概率、期望新增相符项和信息增益
- 候选区同时统计完整卡数量与判定组数量
- 测试模式可公开随机目标卡，体验完整求解过程
- 小游戏模式可隐藏目标卡并自行挑战
- 后台规模测试按照与实操相同的推荐逻辑模拟完整活动，并支持 1／2／4／8 路并行（按设备能力限制，默认推荐 4 路）
- 当前活动可导出为 JSON，并在隔日或另一台设备上导入继续；没有导出文件时也可按“题号｜行动｜结果”逐行补录
- 支持深色／浅色主题、随机壁纸以及中文／英文高清卡图

## 快速开始

本项目不需要安装，也不需要联网运行。

1. 下载仓库源码并解压。
2. 直接打开 `dist/index.html`。
3. 按活动界面填写初始线索，再依次记录提示和挑战反馈。

浏览器会把当前活动进度和自定义预设保存在本机，不会上传这些数据。

## 安装高清卡图（可选）

卡图体积较大，因此不放在源码仓库中。请前往 [高清卡图资源 v1](https://github.com/gumiajer21/card-decoder/releases/tag/card_images-v1) 下载：

- `card-images-zh.zip`：简体中文高清卡图
- `card-images-en.zip`：英文高清卡图

把压缩包中的文件夹解压到 `dist` 目录。完成后目录应为：

```text
dist/
├─ card-images-zh/
├─ card-images-high/
└─ index.html
```

随后在页面设置中选择中文或英文卡图；选择中文时，缺少某张中文图片会自动尝试英文卡图。

## 求解方法

程序把当前候选卡及其权重视为贝叶斯后验状态，并在有限资源下比较提示和挑战的后续策略树。小候选集使用完整的 Bellman 递归；卡池较大时使用受限深度的可行策略搜索。信息熵只作为解释指标，不会被人为折算成奖励。

规模测试运行在后台线程中，并调用与手动使用相同的推荐逻辑。更完整的数学定义、边界和实验结果见：

- [`模型复审与实现规格.md`](模型复审与实现规格.md)
- [`资源价值实验报告.md`](资源价值实验报告.md)
- [`使用说明.txt`](使用说明.txt)

## 数据说明

`dist/cards-data.js` 使用 MASTER DUEL 卡表与卡片密码映射交叉校准。当前工具统计与游戏内怪兽总数仅有极小差异，但科乐美未公开活动实际抽题名单，活动也可能额外排除少量特殊卡。因此候选结果仍可能存在小幅误差，请结合游戏内实际情况判断。

维护卡池时可运行根目录的 `更新大师决斗卡池.cmd`；相关处理脚本位于 `tools`。

## 项目结构

```text
dist/       可直接打开的网页程序、卡片数据和壁纸
tools/      卡池更新与模拟工作线程构建工具
*.md/txt    使用说明、模型规格、实验报告和素材声明
```
