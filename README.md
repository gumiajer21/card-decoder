# 卡片解码者

《游戏王 MASTER DUEL》“卡片解码者”活动的本地辅助求解器。输入已揭示的线索和每次挑战结果，程序会持续缩小候选卡池，并推荐下一步使用提示还是挑战哪张卡。

**B站 @Gumiajer 制作 · 免费分享**

> 本项目是非官方研究与辅助工具，不能消除目标卡和提示字段带来的随机性，与科乐美无关，请勿用于商业用途。

不想下载本地版时，也可以使用轻量[网页版](https://gumiajer21.github.io/card-decoder-web/)；网页版不包含真实卡图和壁纸，核心求解与活动功能保持一致。

## 主要功能

- 完整卡片数据库支持卡名搜索、六项自由勾选、多条件筛选、排序以及列表／卡图视图；同一字段可取多个值的并集
- 可切换“仅显示符合当前已知信息”，根据边框、属性、种族、等级／阶级／连接、攻击力和守备力筛选候选卡
- 区分“六项点亮”和“整卡通关”：灵摆目标命中组成边框时仍计入相符项，但完整边框不同不会误判通关
- 在同一套策略模型中比较“使用提示”与“进行挑战”
- 显示推荐行动、完全猜中概率、期望新增相符项和信息增益
- 推荐卡、当前选择与同组卡片均可一键复制卡名；判定组可展开查看完整卡片列表
- 候选区同时统计完整卡数量与判定组数量
- 测试模式可使用随机或指定目标卡，并可随机或指定初始揭示字段，便于复现具体案例
- 任意选中的挑战卡都可单独计算期望得分、通关率、信息增益、期望新增相符项和平均剩余候选，不会消耗挑战次数
- 挑战区与推荐区都可打开策略价值对比，自行搜索最多 8 张卡；每张卡固定为首步挑战，之后沿各反馈分支继续使用同一严格策略树，并保留单步指标作为解释
- 正式启用默认活动的“第一猜参考库”：覆盖六类初始揭示的 218 个真实显示状态，均以深度 3、最多 100 万状态离线计算完成；规范活动第一题可直接采用离线结论，后续题只用作实时搜索候选
- 小游戏模式可隐藏目标卡并自行挑战
- 后台规模测试按照与实操相同的推荐逻辑模拟完整活动，并支持 1／2／4／8 路并行及逐路实时状态（按设备能力限制，默认推荐 4 路）
- 当前活动可导出为 JSON 文件并直接选择文件导入；没有导出文件时也可使用逐项补录向导恢复行动
- 支持深色／浅色主题、随机壁纸以及中文／英文高清卡图
- 顶部提供独立的常见问题、B站介绍视频和版本记录入口

## 当前版本更新

- 第一猜参考库转为正式功能，并可在手动求解与规模测试中独立启用或关闭
- 按游戏实际规则修正灵摆复合边框，并要求录入游戏揭示的完整目标边框
- 修正六项点亮被误判为整卡正确，以及等价行动剪枝遗漏真实通关结果的问题
- 规模测试支持 1／2／4／8 路并行，并分别展示每一路正在进行的活动与实时结果
- 活动导入／导出移动到顶部，可直接读取 JSON 文件，也可用逐项勾选向导补录旧行动
- 数据库六项条件全部支持直接多选；同一项内取并集，不同项之间取交集
- 候选区域扩展为完整数据库，可按当前已知信息筛选，并切换列表或卡图图格
- 修正活动轨迹中挑战条目的窄列文字排版
- 同步网页版的信息入口、复制卡名、同组卡片查看与完整活动轨迹交互
- 六项线索改为更接近游戏界面的纵向条形布局，便于快速对照录入
- 测试模式增加指定目标与指定初始揭示；挑战区增加指定卡收益分析

并行测试的加速通常不会与并行数成正比。各任务仍会竞争 CPU、内存带宽与浏览器线程资源，设备出现降频或内存压力后，单路求解速度也会下降；默认推荐 4 路，8 路更适合核心数和散热条件较好的设备。

## 快速开始

本项目不需要安装，也不需要联网运行。

1. 下载仓库源码并解压；如只想使用程序，也可以下载 Release 中的成品包。
2. 直接打开 `dist/index.html`。
3. 按活动界面填写初始线索，再依次记录提示和挑战反馈。

浏览器会把当前活动进度和自定义预设保存在本机，不会上传这些数据。

## 安装高清卡图（可选）

卡图体积较大，因此不放在源码仓库中。请前往 [高清卡图资源 v1](https://github.com/gumiajer21/card-decoder/releases/tag/card_images-v1) 下载：

- `card-images-zh.zip`：简体中文高清卡图
- `card-images-en.zip`：英文高清卡图

把压缩包中的文件夹解压到 `dist` 目录。完成后目录应为：

```text
dist/
├─ card-images-zh/
├─ card-images-high/
└─ index.html
```

随后在页面设置中选择中文或英文卡图；选择中文时，缺少某张中文图片会自动尝试英文卡图。卡图并非求解所必需，缺失时程序仍可正常运行。

## 求解方法

程序把当前候选卡及其权重视为贝叶斯后验状态。稳定搜索在小候选集使用完整 Bellman 递归，卡池较大时使用受限深度策略树；信息熵只作为解释指标，不会被直接折算成奖励。

只要当前题目仅录入一项初始线索，就会命中随程序附带的第一猜参考库。该库穷举六类字段的 218 种真实初始揭示值；每项均在深度 3、100 万状态上限内完成。等级／阶级／连接按游戏显示值建立索引，挑战匹配位掩码只用于反馈判定。若当前正是默认活动的第一题且资源未消耗，会直接使用其完整的离线策略结论；在后续题目或资源不同的活动中，参考库只补充高质量挑战候选，提示与挑战的最终取舍仍由实时求解器按当前资源计算。候选很大时，挑战动作采用均衡的覆盖集合而非声称对全部 9,000 余张挑战卡全穷举；页面会明确说明这一边界。

规模测试运行在后台线程中，并调用与手动使用相同的推荐逻辑。更完整的数学定义、边界和实验结果见：

## 数据说明

`dist/cards-data.js` 使用 MASTER DUEL 卡表与卡片密码映射交叉校准。当前工具统计与游戏内怪兽总数仅有极小差异，但科乐美未公开活动实际抽题名单，活动也可能额外排除少量特殊卡。因此候选结果仍可能存在小幅误差，请结合游戏内实际情况判断。

维护卡池时可运行根目录的 `更新大师决斗卡池.cmd`；相关处理脚本位于 `tools`。
